# PaneDock

**Fast Multi-Pane File Manager** — C# / WPF / .NET 10 기반 Windows 파일 관리자입니다.

Windows 11 스타일의 한 화면에서 1~4개 파일 탐색 패널을 자유롭게 배치하고,
폴더 분석, 대량 이름·확장자 변경, 빠른 파일 검색을 통합하는 것을 목표로 합니다.

### 현재 사용 가능한 기능

- **첫 실행 기본 위치: 내 PC.** C:, D:를 비롯한 현재 연결 드라이브가 목록에 표시되며 더블클릭으로 진입. 각 패널의 **PC** 버튼으로 언제든 돌아올 수 있음
- **마지막 작업공간 자동 복원**: 종료 전 사용한 4개 패널의 폴더 경로와 탭 목록·활성 탭, 패널 배치·활성 패널이 다음 실행 시 복원됨. 삭제되었거나 접근할 수 없는 폴더는 해당 탭만 **내 PC**로 전환
- **창 위치·크기 자동 복원**: 최대화 여부까지 기억. 모니터가 분리되어 이전 창 위치가 화면 밖이면 기본 위치에서 시작
- **작업표시줄을 제외한 최대화**: 현재 창이 위치한 모니터의 Windows 작업 영역에 맞춰 최대화. 하단 상태·폴더 분석 영역이 작업표시줄에 가려지지 않으며 기존 창 크기 복원 유지
- **탭별 보기 설정 복원**: 파일명 필터, 필터 표시 여부, 숨김 항목, 정렬 컬럼/방향을 독립 저장. 폴더를 바꾸면 기존 필터 문자열을 지움
- **폴더 우선 정렬**: 모든 탐색 패널에서 폴더를 파일보다 먼저 표시. 기본은 이름 오름차순이며 이름/크기/날짜/유형 등 정렬 컬럼과 오름차순·내림차순은 각 그룹 내부에 적용. 탭 이동·외부 파일 갱신에도 유지
- **이름으로 빠른 선택 이동**: 파일 목록에 포커스가 있을 때 A–Z 또는 Shift+A–Z 입력으로 현재 표시된 파일/폴더 이름 앞부분을 찾아 선택·스크롤. 연속 입력은 접두사로 누적, 1초 이후 새 탐색, 같은 글자 반복은 더 긴 접두사에 해당하지 않을 때 다음 후보로 이동. 주소창/필터/전체 검색 입력과 Ctrl/Alt 단축키에는 영향 없음.
- **탭 우클릭 메뉴 및 드래그**: 탭 복제, 다른 패널(PANE 1~4)로 이동. 탭 머리글을 끌어 **같은 패널에서 순서 변경**, 다른 패널로 끌어 **탭 이동** 가능하도록 구현. 이동 대상이 숨겨져 있으면 메뉴 명령으로 레이아웃 전환. **파일 드래그는 복사, 탭 드래그만 이동**하도록 구분. 실제 Windows OLE 마우스 입력으로 같은 패널 재정렬 및 다른 패널 이동, 경로·필터·정렬 유지 확인
- **상단 파일 검색 팝업 (Phase 4)**: 상단 검색창에 입력하면 **해당 검색창 바로 아래로 결과 팝업이 펼쳐집니다**. 상단 돋보기 또는 Enter로 검색 실행. Everything 인덱스 자동 검색(230ms 대기), 검색 범위/문법, **Ctrl/Shift 다중 선택·Ctrl+A·Delete 휴지통 이동** 지원. 하단에는 별도 검색 버튼을 두지 않음. 입력 중 이전 검색이 취소되면 결과를 버리고 직접 디스크 검색으로 잘못 전환하지 않도록 보호
- **하단 폴더 분석 (Phase 5)**: 활성 패널에서 하나 또는 여러 폴더를 선택하면 **메인 화면 하단에 파일 수·하위 폴더 수·총용량 합계가 자동 표시**됩니다. 해당 영역을 클릭하면 **별도 창 없이 폴더별 상세 내역이 펼쳐지며**, '다시 계산' 버튼도 제공합니다. 부모/자식 폴더가 함께 선택되면 이중 합산을 방지합니다. 패널 전환/선택 변경으로 중단한 이전 분석의 부분 결과는 표시하지 않습니다
- **검색 결과·폴더 분석 다크 모드 개선**: 두 팝업의 DataGrid 행·셀·열 머리글에 Light/Dark 동적 배경·텍스트·선택색을 명시하고 비활성 포커스의 Windows 기본 선택색도 테마에 맞춰 교체해 글자색과 배경색이 겹치지 않게 함. 폴더 분석 팝업은 버튼 클릭 이벤트가 끝난 다음 열어 즉시 닫히는 증상을 예방
- **일괄 파일명/확장자 변경 (Phase 6)**: 선택한 파일, 파일 대화상자 또는 현재 폴더 전체 파일을 대상으로 문자열 치환·접두사·접미사·확장자 통일/제거. 기존/변경 후 이름의 미리보기 및 충돌 검사 후 사용자 확인을 거쳐 적용. 마지막 변경 되돌리기 지원
- **바탕화면 바로가기**: 각 패널의 **바탕화면** 버튼으로 Windows 바탕화면 폴더로 이동
- **첫 실행 기본 테마: Light.** 상단 테마 버튼에 현재 Light/Dark 상태가 표시되며 전환한 선택이 재실행 시에도 유지됨
- **전용 PaneDock 아이콘**: 4분할 파일 탐색 패널과 폴더를 형상화한 아이콘을 Windows 실행 파일, WPF 창 아이콘 및 상단 커스텀 타이틀바에 적용
- **Git 파일 상태 오버레이**: Git 저장소의 파일·폴더 아이콘 **왼쪽 아래에 9×9의 작은 상태 표시**(✓ 변경 없음/커밋됨, ● 수정 중, + 스테이징됨, ? 미추적, ! 병합 충돌). `?`는 작은 크기에서도 보이도록 렌더링하며, **Git 상태가 없는 파일·폴더(저장소 밖·무시 항목 등)는 배경까지 완전히 숨겨** 빈 사각형이 나타나지 않음. 아이콘을 가리키면 상태 설명 툴팁 표시. 하위 파일에 변경 사항이 있는 폴더에도 상태가 전파되며, 패널 상단에는 현재 브랜치가 표시됨. 설치된 Git CLI의 `git status --porcelain`과 `git ls-files`로 읽기 전용 조회. Git 미설치 시 기존 탐색 화면 유지. 여러 패널이 같은 저장소를 열 때 조회 결과 공유, 5초 간격 갱신 및 F5 즉시 새로 고침. ✓는 **로컬 Git 기준 변경 없음**을 뜻하며 원격 푸시 완료를 뜻하지 않음
- 1 / 2(좌우·상하) / 3(2종) / 4(2×2) 패널 배치와 마우스·키보드 분할 크기 조절. **각 레이아웃의 가로/세로 비율을 별도로 저장하고 재실행 시 복원**
- 패널별 독립 탭, 경로, 뒤로/앞으로 및 필터·숨김 항목 상태
- **PC** 버튼으로 내 PC 목록 복귀, Breadcrumb/주소 입력/상위 폴더 이동
- **Breadcrumb 경로 탐색**: 주소의 드라이브/상위 폴더를 클릭해 이동, 펜(✎) 버튼이나 Ctrl+L로 전체 경로 직접 입력. Enter 이동 / Esc 취소. 경로 입력란에 정확히 `cmd` 또는 `cmd.exe`를 입력하면 **현재 패널 폴더를 작업 디렉터리로 하여 명령 프롬프트 실행** (내 PC에서는 사용자 홈 폴더)
- **단축키 도움말**: 창 오른쪽 상단의 **? 버튼** 또는 **F1**로 단축키 목록을 창 안의 팝업으로 표시. 탐색·검색, 파일·폴더, 탭 관리, 도움말 항목별로 분류하여 스크롤할 수 있음. F1·Esc·닫기(×) 버튼으로 닫거나 팝업 바깥을 클릭해 닫을 수 있음. 현재 구현된 탐색기 단축키 목록과 도움말 항목의 일치 여부를 자동 테스트로 확인
- **탐색기 단축키**: **Backspace / Alt+←** 이전 방문 폴더, **Alt+→** 앞으로, **Alt+↑** 상위 폴더, **F5 / Ctrl+R** 새로 고침, **Ctrl+L / Alt+D / F4** 주소 편집, **Ctrl+F** 폴더 필터, **Ctrl+E / F3** 전체 검색, **Ctrl+T / Ctrl+W / Ctrl+Tab / Ctrl+Shift+Tab** 탭 조작, **F6** 파일 목록/폴더 트리 포커스 변경. 파일 목록에서는 Enter 열기, Ctrl+A 모두 선택, F2 이름 변경, Ctrl+C/X/V 복사·잘라내기·붙여넣기, Delete/Ctrl+D 휴지통 삭제, Shift+Delete 확인 후 영구 삭제, Alt+Enter 속성, Shift+F10 컨텍스트 메뉴를 지원. Ctrl+Shift+N 새 폴더, Ctrl+Alt+N 새 파일 및 Ctrl+V 붙여넣기는 패널 전체에서 사용 가능. 주소/필터 입력 중 Backspace·Delete·Ctrl+C/X/V 등은 기본 텍스트 편집 동작을 유지하지만, **Ctrl+T/W 및 Ctrl+Tab 계열의 탭 단축키는 계속 사용 가능**
- 각 패널의 **폴더 트리**에서 드라이브와 하위 폴더 탐색. 펼친 폴더를 비동기로 읽고 현재 탭의 경로에 맞춰 트리 선택 갱신
- **이름 / 확장자 / 크기 / 유형 / 수정 날짜 / 생성 날짜** 목록과 열 정렬. **Windows 연결 프로그램의 실제 파일 형식 아이콘**을 Shell에서 조회해 확장자·폴더·드라이브별로 캐시(최대 256종), 불러올 수 없을 때 기존 종류별 경량 아이콘 표시. 개별 실행 파일 고유 임베디드 아이콘은 후속 검토
- **가로·세로 스크롤**: 파일 목록/폴더 트리와 검색·분석·일괄 변경 목록에서 양방향 스크롤바를 자동 표시. 긴 파일명 및 경로에 맞춰 컬럼 너비 확장, 파일명 툴팁 지원
- 폴더 더블클릭으로 이동, 파일 더블클릭으로 Windows 기본 연결 프로그램 실행
- 돋보기 버튼으로 **현재 폴더 파일명 필터**, 숨김·시스템 파일 표시 옵션
- 다중 선택과 상태 표시줄의 표시/전체/선택 수
- **외부 파일 변경 자동 감지**: 현재 열려 있는 폴더의 파일 생성·수정·삭제·이름 변경을 감지해 목록 자동 갱신. 짧은 시간의 변경 이벤트 병합, 선택/정렬/현재 폴더 필터 유지, 같은 폴더를 연 여러 패널 동시 반영
- **드라이브 연결 상태 확인**: 6초 간격으로 C:/D:/USB 등의 드라이브 목록 변화 확인. 연결·분리 시 열린 '내 PC' 탭의 목록을 자동 갱신
- **네트워크 공유 단절·복구 대응**: UNC·매핑 드라이브가 연결되지 않은 경우 저장된 탭 경로를 '내 PC'로 강제 변경하지 않고 재연결을 기다림. 네트워크 감시 폴더에서만 약 6초 간격으로 무음 단절을 감지해 자동 재접속하고 복구 후 목록·트리를 읽음. 상태 확인은 한 폴더당 한 번만 수행하여 느린 네트워크 응답 중 감시 요청이 쌓이지 않음. 로컬 폴더 탐색 시 불필요한 중복 경로 검사를 하지 않음. `F5`는 새 목록을 성공적으로 읽은 후 교체해 연결 오류 중 이전 파일 목록·선택 상태를 보존. 느린 공유 폴더의 감시기 생성·재접속 및 드래그/이름 충돌 사전 검사는 UI를 차단하지 않도록 별도 스레드에서 수행. **실제 로컬 SMB 매핑 해제/복구와 UNC 경로 접근 불가/복원 실기 확인. 외부 서버 전원·물리 LAN 단절은 현장 검증 범위**
- **대량 목록 점진 표시**: 초기 256개를 전달한 뒤 512/1024/…/16,384개까지 적응형 배치를 늘려 한 묶음당 컬렉션 변경 알림 1회로 갱신. 실제 10만 파일 재진입 자동화 왕복 측정 48.7초→5.0초로 개선
- **Windows Shell 우클릭 메뉴**: 파일·폴더·다중 선택·빈 공간과 Shift+F10에서 Windows 클래식 Shell 메뉴 표시. 설치된 Notepad++, 반디집, Git 등 확장이 자동으로 나타나며 동적 하위 메뉴도 지원. PaneDock 기능 하위 메뉴에서 새 폴더·새 파일, 이름 변경, 복사·잘라내기·붙여넣기, 삭제 및 영구 삭제를 사용. 식별 가능한 표준 파일 명령은 기존 안전 처리로 연결하고 Shell 메뉴 생성 실패 시 기존 메뉴로 대체. 네이티브 메뉴는 Windows 테마를 따르며 Windows 11 신형 메뉴 전용 확장은 지원하지 않을 수 있음. Windows 탐색기와 파일 클립보드 공유. **새 파일**은 파일명을 입력해 빈 파일(0B)로 생성하며 기존 파일을 절대 덮어쓰지 않음. **파일·폴더 삭제는 선택 개수를 보여주고 확인받으며** 이름 변경/폴더 생성 시 기존 이름 충돌을 검사
- **파일 복사 드래그 앤 드롭**: 파일 목록에서 다중 선택 후 다른 패널·폴더 목록·폴더 트리·탭으로 끌어 놓으면 **복사(Copy)만 수행**, 원본 유지. WPF DataGrid가 드래그 직전 다중 선택을 단일 선택으로 축소하는 경우를 방지하기 위해 마우스를 누를 때 선택 목록을 보관합니다. 외부 Windows 탐색기의 일반 파일 드롭도 지원. 대상 폴더 연결·원본 존재·폴더 자기 자신/하위 복사 여부를 먼저 검증하며 **기존 이름 충돌은 사전 경고 후 Windows Shell에서 최종 처리**. Windows 작업 취소는 일반 실패 경고 없이 상태로 안내
- **Shell 작업 완료 결과 안내**: 파일 복사·이동·삭제 시 선택한 최상위 항목별 Windows Shell 응답을 집계해 **전체 요청 개수, 실제 완료 개수, 미완료 개수**를 상태 표시줄에 약 8초 동안 표시. 목록 자동 갱신으로 결과 문구가 사라지지 않으며, 취소 또는 부분 완료를 정상 전체 완료로 잘못 표시하지 않음. 다른 폴더에 있는 같은 이름의 파일이나 상위 폴더·하위 항목을 동시에 붙여넣는 위험한 조합은 실행 전 차단. 일부 이동 후 중단되면 **원래 잘라내기 클립보드를 자동으로 지우지 않음**. 하위 파일 완료는 상위 폴더 완료로 합산하지 않고, 재귀 폴더 중단 시 완료 여부를 확정할 수 없는 폴더를 별도 안내. 실제 진행창 취소·잠금·ACL 오류, 삭제/복원 및 OLE 실기 확인
- 파일 작업 후 관련 폴더 목록과 트리 갱신. 외부 변경도 자동 감지하며, 누락되거나 네트워크 오류가 발생한 경우 F5로 강제 새로 고침 가능
- 현재 폴더에서만 파일명 필터가 적용되며 다른 경로로 이동하면 필터 입력값은 초기화됨
- 우측 상단 최소화·최대화/복원·닫기 버튼

작업공간은 폴더/탭/패널·창 위치·크기·정렬·필터·테마·분할 비율을 변경하면 짧은 입력 대기 후, 그리고 **정상 종료할 때** 사용자 프로필의
`%APPDATA%\PaneDock\workspace.json`에 자동 저장합니다. JSON 파일은 임시 파일 작성 후
교체하여 저장합니다. 기존 세션 파일은 그대로 호환되며, 테마/비율 정보가 없으면
**Light 및 1:1 분할**을 사용합니다. 손상되었거나 지원하지 않는 형식은 무시하고 기본
**Light 테마 / 내 PC** 작업공간으로 시작합니다. 경로·탭·테마·비율을 함께 초기화하려면
PaneDock 종료 후 이 파일을 삭제하면 됩니다. 비율은 10%~90% 범위에서 안전하게 보정합니다.
파일 내용은 해당 Windows 사용자 컴퓨터에만 저장되며 Git 저장소에는 기록되지 않습니다.

단축키는 **상단 `?` 도움말 버튼 또는 F1**로 확인할 수 있습니다. 특히 `Backspace`와
`Alt+←`는 **이전 폴더**, `Alt+↑`는 **상위 폴더**로 이동합니다.

### 전체 검색: Everything 인덱스 / 직접 검색

패널 내부 돋보기와 Ctrl+F는 **현재 폴더 목록 필터**입니다. **전체 파일 검색**은
메인 **상단 검색창** 하나로 사용합니다. 검색어를 입력하면 해당 입력창 **바로 아래**
툴팁 형태의 검색 결과 패널이 열리고, Everything 인덱스가 연결돼 있으면 약 230ms
대기 후 자동 갱신합니다. **상단 돋보기 / Enter**로 검색을 명시적으로 실행하거나
검색 팝업을 열 수 있으며, 입력창과 팝업에 검색어 입력란이 중복 표시되지 않습니다.
팝업의 **× 또는 Esc**로 닫고, 다른 영역을 클릭해도 닫을 수 있습니다.
새로 열 때는 기본적으로 **PC 전체** 검색 범위로 시작하고, 열린 팝업에서는
`현재 폴더` 또는 직접 경로 입력으로 범위를 제한할 수 있습니다.
하단은 폴더 분석 요약만 표시하며 별도 전체 검색 버튼을 두지 않습니다.

1. [Everything 공식 다운로드](https://www.voidtools.com/downloads/)에서 **일반 버전**
   (1.4.1 이상, IPC 지원)을 설치하고 실행합니다. Lite 버전은 IPC를 지원하지 않습니다.
   PaneDock는 Everything 프로그램이나 인덱스를 자동으로 설치·생성하지 않습니다.
2. Everything **데스크톱 앱이 현재 Windows 사용자 세션에서 IPC 연결 가능한 상태**이면 **상단 검색창**에 문자를 입력한 뒤 약 **230ms** 후
   결과를 자동 갱신합니다. `*.pdf`, 공백으로 단어 AND 검색 등 Everything 검색 문법을 지원합니다.
3. 검색 위치를 비워두면 **Everything에 인덱싱된 모든 위치**를 찾습니다.
   `현재 폴더` 버튼이나 C:/D:/UNC 경로를 입력하면 범위를 제한하며,
   **하위 폴더 포함**을 끄면 바로 아래 항목만 검색합니다.
4. Everything이 실행되지 않거나 IPC 연결이 불가능하면 상태 영역에서 원인을 안내합니다.
   **서비스 세션(0)에만 Everything이 실행 중이고 데스크톱 사용자 세션에 인스턴스가 없는 경우**도
   구분해 표시합니다. 인덱스 연결이 없을 때 **상단 돋보기/Enter만으로 전체 드라이브를 자동 순회하지 않습니다.**
   인덱싱되지 않은 경로나 네트워크 공유를 검색할 때만 명시적으로 **직접 검색(느림)** 체크박스를
   선택하고 Enter를 누르세요. 직접 검색은 디스크를 순회하므로 오래 걸릴 수 있습니다.

결과는 최대 **5,000개**까지 표시합니다. 인덱스 검색은 실제 전체 결과 개수와
소요 시간(ms)을 함께 표시합니다. Everything 인덱스에 등록되지 않은 위치는 검색
결과에 나타나지 않으며, Everything이 없는 PC에서는 동일한 인덱스 속도가 제공되지 않습니다.

**오픈소스 배포:** 공식 SDK의 64비트 IPC 클라이언트 `Everything64.dll`을
PaneDock와 함께 배포합니다. MIT 라이선스 및 관련 저작권 고지 파일은
`src/PaneDock.App/Native/Everything.LICENSE.txt`입니다.
Everything 본체와 데이터베이스는 PaneDock 배포에 포함하지 않습니다.

**검색 결과 정리 및 삭제:** 검색 결과는 **Ctrl/Shift 다중 선택**과 **Ctrl+A 전체 선택**을
지원합니다. 여러 파일을 선택한 뒤 **Delete** 또는 검색 팝업 내 **선택 삭제**를 누르면
선택된 파일·폴더 수를 확인하는 대화상자가 나타납니다. 승인하면 Windows Shell을 사용해
**휴지통 이동을 요청**하며, 취소하거나 일부 실패한 경우 실제 파일 존재 여부에 따라
검색 결과와 열린 탐색 패널을 갱신합니다. 폴더를 삭제하면 그 안의 파일과 하위 폴더도
함께 삭제되므로 확인 메시지를 읽어야 합니다. **Shift+Delete 영구 삭제는 검색창에서
지원하지 않습니다.** 휴지통을 지원하지 않는 위치에서는 Windows가 영구 삭제를 경고할 수 있습니다.

### 메인 화면 하단 폴더 분석

별도 폴더 분석 창을 열지 않습니다. **활성 탐색 패널에서 하나 또는 여러 폴더를 선택**하면
메인 화면 하단에 파일 수·하위 폴더 수·총용량이 비동기로 자동 계산됩니다.
**하단 상태 영역을 클릭**하면 선택 폴더 각각의 파일 수·하위 폴더 수·용량·접근 불가
항목 수가 간단한 상세 팝업으로 나타납니다. 팝업의 **↻ 다시 계산** 버튼으로
재분석할 수 있습니다. 같은 경로나 부모·자식 폴더를 함께 선택하면 이중 집계하지
않으며, 재분석 지점과 접근 불가 항목은 건너뜁니다.
선택·탭·활성 패널이 바뀌면 이전 계산을 취소하고 새 선택을 분석합니다.
**폴더 선택이 없으면 전체 드라이브를 자동 재귀 분석하지 않습니다.**

### Phase 6 일괄 변경 사용법 및 안전성

탐색 패널에서 여러 파일을 선택하고 상단 **일괄 변경**을 누르세요. 또는 변경 창에서
`파일 선택…` / `현재 폴더 전체` 버튼으로 파일을 추가할 수 있습니다.
파일명 '찾을 문자열/바꿀 문자열', 접두사, 접미사를 적용하며 **확장자 변경**을 체크하면
`csv`나 `.csv`를 입력해 서로 다른 확장자의 파일을 한꺼번에 변경합니다. 빈 확장자는 제거입니다.

**미리보기 → 충돌·금지 이름 확인 → 변경 실행 → 확인** 순서가 필수입니다.
다른 파일과 이름이 충돌하거나 결과 이름이 중복되면 **실행이 비활성화**됩니다.
실행 직전에도 원본/대상 경로를 다시 검증하고 덮어쓰기 없이 각 파일을 같은 폴더의
임시 이름으로 옮긴 다음 최종 이름을 적용합니다. 중간에 오류 또는 취소가 발생하면
원래 이름으로 자동 복원을 시도하며, 복원에 실패한 경로가 있다면 사용자에게 표시합니다.
미리보기 시 파일 크기와 생성/수정 시각도 기록해 실행·되돌리기 전 변경 여부를
재검사합니다. **동작 중에는 변경 창을 닫을 수 없고**, 닫기를 요청하면 먼저

## Release 빌드와 설치 (Windows x64)

설치 프로그램과 소스 빌드·설치·제거용 PowerShell 및 CMD 파일을 제공합니다.
관리자 권한 없이 현재 사용자 계정에 배포할 수 있습니다.

| 실행 파일 | 기능 | 결과 경로 |
| --- | --- | --- |
| `installer\build-installer.cmd` | 배포용 콘솔 설치 프로그램 생성 | `build\Installer\PaneDock-Setup-V<버전>.exe` |
| `build.cmd` / `build.ps1` | .NET 10 SDK 확인 → win-x64 Release self-contained publish | `build\Release\PaneDock.exe` |
| `install.cmd` / `install.ps1` | 빌드 → 프로그램 설치 → Windows 앱 목록과 시작 메뉴에 등록 | `%LOCALAPPDATA%\Programs\PaneDock\PaneDock.exe` |
| `uninstall.cmd` / `uninstall.ps1` | 관리 파일, 시작 메뉴 바로가기, Windows 앱 항목 제거 | 사용자 설정 및 비관리 파일 보존 |

### 배포용 설치 파일

새 버전을 배포할 때는 [PaneDock.App.csproj](src/PaneDock.App/PaneDock.App.csproj)의
`<Version>` 값을 변경하세요. 빌드된 앱의 버전이 설치 파일 이름과 속성에 반영되며,
앱 제목과 Windows 설치된 앱 목록에도 같은 버전이 표시됩니다.

프로젝트 루트에서 설치 파일을 빌드하고 검증합니다.

```powershell
.\installer\build-installer.cmd --no-pause
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\Installer.Tests.ps1
```

버전이 `1.0.0`이면 `build\Installer\PaneDock-Setup-V1.0.0.exe`가 생성됩니다.
받는 PC에서는 이 파일 하나로 .NET SDK 설치나 NuGet 다운로드 없이 설치할 수 있습니다.

- **Install**은 현재 사용자 계정에 새로 설치합니다. 기본 경로는 `%LOCALAPPDATA%\Programs\PaneDock`입니다.
- **Modify**는 기존 설치를 업데이트하거나 복구합니다. 이전 스크립트로 설치한 경우에도
  앱을 종료하고 **Modify**를 실행하면 Windows 앱 목록에 등록됩니다.
- **Uninstall**은 설치 파일과 바로가기를 제거하고 사용자 설정 및 비관리 파일을 보존합니다.
  Windows에 등록된 이후에는 **설정 → 앱 → 설치된 앱** 또는 **제어판 → 프로그램 및 기능**에서도 제거할 수 있습니다.

콘솔에서 실행할 때는 `PaneDock-Setup-V1.0.0.exe install`, `PaneDock-Setup-V1.0.0.exe modify`,
`PaneDock-Setup-V1.0.0.exe uninstall`로 메뉴를 바로 선택할 수 있습니다. 명령 뒤에
`--what-if`를 붙이면 변경 내용을 미리 볼 수 있습니다.

### 소스에서 빌드, 설치 또는 제거

아래 명령은 프로젝트 루트에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1 -InstallDirectory 'D:\Apps\PaneDock'
powershell -ExecutionPolicy Bypass -File .\build.ps1 -WhatIf
powershell -ExecutionPolicy Bypass -File .\install.ps1 -WhatIf
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -WhatIf
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

`build.cmd` 또는 `install.cmd`를 더블클릭하면 PowerShell을 실행하고 종료 전에
결과를 확인할 수 있습니다. CMD 래퍼는 PowerShell 종료 코드를 그대로 전달합니다.

- 호환되는 **.NET SDK 10 이상**을 찾아 재사용합니다. 없는 경우 Microsoft 공식 설치
  스크립트로 `%LOCALAPPDATA%\Microsoft\dotnet`에 .NET 10 SDK(x64)를 설치합니다.
  시스템의 영구 PATH는 변경하지 않습니다.
- 빌드는 **.NET과 WPF 런타임을 포함**하므로 배포 시 `build\Release` 전체 폴더를
  다른 Windows x64 PC에 복사하면 해당 PC에서 .NET SDK/런타임 설치 없이 실행할 수 있습니다.
- 설치는 시작 메뉴에 **PaneDock** 바로가기를 생성합니다. 사용자 설정
  (`%APPDATA%\PaneDock`)은 초기화하지 않습니다.
- 업데이트는 완전한 새 배포본을 준비한 뒤 기존 관리 설치 폴더를 교체합니다.
  설치 관리 목록(`.panedock-install.json`)이 없는 기존 폴더나 사용자 파일이 혼재한
  폴더는 안전을 위해 업데이트하지 않습니다. 별도 빈 폴더에 설치하거나 먼저
  기존 설치 및 개인 파일을 정리하세요.
- 시작 메뉴의 **Uninstall PaneDock** 바로가기, 설치 폴더의 `uninstall.ps1`,
  또는 소스 저장소의 `uninstall.cmd`로 제거할 수 있습니다.
  제거 시 관리 파일만 삭제하고 비관리 파일과 AppData 사용자 설정은 보존합니다.
- SDK 및 NuGet/런타임 패키지가 로컬에 없으면 다운로드에 인터넷이 필요할 수 있습니다.
- 작업 전에 실행 중인 PaneDock을 종료하세요. `-WhatIf`에서는 빌드/설치하지 않습니다.
- 작업 기록은 `%TEMP%\PaneDock-install-<id>.log`에 저장됩니다.
  Publish 실패 시 기존 설치 대상은 변경하지 않습니다.
